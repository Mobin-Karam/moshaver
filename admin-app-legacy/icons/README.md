# Moshaver icon pack

Custom one-color SVG family for the Student PWA. Icons use a 24×24 coordinate system, rounded 2px strokes and no external dependencies. `logo.svg` / `moshaver-mark.svg` combine an advisor conversation bubble, an open book and a check mark.

The same core pack is mirrored in the Admin application so system actions keep a consistent visual language.

## v1.4 additions
`send.svg`, `retry.svg`, `exam-lock.svg`, `exam-ready.svg`, `bell-unread.svg`, `check-double.svg` are custom lightweight SVG assets for chat, timed exams, retries and notifications.
